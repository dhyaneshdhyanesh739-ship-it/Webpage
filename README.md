# Web Application Development - HTML Practical Exercises

Welcome to the **Webpage** repository! This project contains a collection of HTML practical web pages demonstrating structured layouts, nested tables, timetables, and student profile pages.

---

## 📁 Repository Structure

```
.
└── html-practical/
    ├── index.html                  # Main landing / navigation page
    ├── college-timetable.html      # College timetable page using HTML tables
    ├── college-nested-table.html   # Advanced college table with nested tables
    ├── student-nested-table.html   # Student records displayed using nested tables
    └── student-profile.html        # Comprehensive student profile page
```

---

## 🌐 Web Pages Overview

| File | Description |
| :--- | :--- |
| **`index.html`** | Main entry page linking to all practical exercises. |
| **`college-timetable.html`** | Displays a structured college class schedule. |
| **`college-nested-table.html`** | Demonstrates complex department structures using nested tables. |
| **`student-nested-table.html`** | Visualizes student academic records using nested tables. |
| **`student-profile.html`** | A personal student profile page. |

---

## 🚀 How to View Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dhyaneshdhyanesh739-ship-it/Webpage.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd Webpage/html-practical
   ```
3. **Open `index.html`** in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, etc.).
